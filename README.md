# 基金金字塔买卖提醒助手 (Fund Buy&Sell Reminder)

一款专为中国公募基金投资者打造的**策略记账与智能买卖点提示 Web 应用 (PWA)**。

---

## 🌟 核心功能特色

### 1. 实时行情、开盘倒计时与法定节假日智能识别
* **实时盘中估值与晚间官方净值自动校准**：直连天天基金/东方财富官方最新批量估值 API，自动解析盘中实时估值、涨跌幅。当晚官方正式净值更新后，自动将收盘参考估值校准替换为官方净值。
* **盘中状态与开盘倒计时**：
  * **开盘交易时段**（09:30-11:30、13:00-15:00）：状态胶囊显示绿色呼吸指示灯与 `实时盘中交易时间：hh:mm:ss`。
  * **非开盘时段**（午间休市、收盘后及节假日）：自动计算距离下一次开盘的剩余时间 `距离开盘：hh:mm:ss`。
* **法定节假日智能休市日历**：内置当年法定休市安排，并支持静默轻量自动同步；遇到法定节假日倒计时均会自动顺延跨越整个假期，准确指向收假当天 09:30。
* **支持用户自定义定时自动刷新**：在设置面板中可自由开启/关闭自动刷新，并支持自定义刷新时间间隔（单位：分钟，默认 10 分钟）。
* **多级网络降级保障**：优先浏览器直连，配备 Cloudflare Pages Functions、Vercel Serverless 反代及公共代理池兜底。

### 2. 金字塔加仓与倒金字塔减仓策略模型
* **金字塔加仓（越跌越买）**：默认每跌 5%，提示买入总计划预算的 10%、20%、30%、40%。
* **倒金字塔减仓（越涨越卖）**：默认每涨 5%，提示卖出持有仓位的 10%、20%、30%、40%。
* **买卖双基准独立锚定**：买入和卖出可分别独立选择基准方式（初始建仓成本价、固定成本价、上一次成交价、当前持仓成本均价），并支持在旁边直接输入修改基准价格。
* **自定义阶梯微调**：支持自定义步进比例（如跌3%或5%）、自由增删阶梯档位并分配买卖仓位比例，并具备仓位总和校验（不超过 100%）。。
* **实时阶梯指示器**：横向刻度直观展现当前净值处于哪一档位区间、距离下一档还需涨跌多少 %、下一买卖点建议投入金额/赎回份额；未达到买卖点时对应基准刻度槽常亮绿色指示。

### 3. 14:00 后首访智能预警与操作联动
* **14:00 后首访按需提醒**：在交易日 14:00（场外基金申赎决策黄金期）之后，用户当天**首次打开网页或应用时**自动执行策略巡检；若检测到未执行的交易点位，则触发提醒并记录当天状态，杜绝同日内重复弹窗打扰。
* **双重感官提醒**：触发未执行信号时，自动弹出系统原生 Notification 弹窗，并播放 Web Audio 原生合成清脆和弦提示音。
* **告警横幅快捷加减仓**：主界面醒目展示可一键展开/收起的告警横幅，除了复制买卖指令外，还配备快捷加仓/减仓按钮，一键将建议规模带入记账弹窗。

### 4. 基金历程时间轴与加减仓全流程管理
* **纵向历程时间轴**：每个基金均配备可视化时间轴卡片，完整记录初始建仓、加仓记账、减仓赎回、买卖点到达提醒等全生命周期事件，最新时间节点带有脉冲呼吸灯动效提示。
* **时间轴事件快捷修改与删除**：加减仓事件旁配备「✏️ 修改」操作按钮，支持随时修改加减仓金额、确认份额与确认净值；系统严格保证 $\text{加减仓金额} = \text{确认份额} \times \text{净值}$，亦支持误操作单笔删除。
* **全量交易历史重演推演**：无论何时修改或删除历史记录，系统内核算法均会自动按时序完整回溯推演全部交易流水，精确重新计算当前总持有份额、总投入本金、持仓加权均价与已实现盈亏。
* **15:00 未知价自动校准机制**：在 15:00 前执行的加减仓申报先以盘中参考估值暂记（待确认状态）；待收盘官方正式净值公布后（当晚或次日刷新时），系统自动追踪并校准真实成交净值与份额。

### 5. 纯本地私密存储与 JSON 备份
* 所有持仓与交易流水均安全存储在浏览器的 LocalStorage 中，不经第三方服务器。
* 提供一键「JSON 导出备份」与「JSON 导入恢复」，换手机或清缓存无后顾之忧。

### 6. 移动端深度适配与全平台 PWA
* **双主题与双配色习惯**：深色黑曜石磨砂 / 浅色清新通透一键切换，完美适配「红涨绿跌（国内习惯）」与「绿涨红跌（国际惯例）」，按钮悬停高对比度保障。
* **网络优先缓存**：采用 Network-First Service Worker 缓存策略，结合 Cloudflare `_headers` 与资源版本号，彻底消除托管平台强缓存滞后问题。
* **PWA 原生体验**：视口锁定与 `touch-action: manipulation` 禁用双击放大误触，完整支持 iOS Safari「添加到主屏幕」全屏沉浸运行。

## 🚀 免费部署方案 (推荐：Cloudflare Pages / Vercel)

本项目无需购买云服务器或数据库，可 100% 永久免费部署至全球主流托管平台。

### 方案 A：部署在 Cloudflare Pages (推荐，全球极速且自带反代)

1. 将本项目代码推送到你个人的 GitHub 仓库中。
2. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，在左侧导航栏点击 **Workers 和 Pages** -> **创建应用程序** -> 选择 **Pages** -> **连接到 Git**。
3. 选择你刚刚推送的代码仓库：
   * **框架预设 (Framework preset)**：选择 `None` (纯静态)
   * **构建命令 (Build command)**：留空
   * **构建输出目录 (Build output directory)**：填入根目录 `.` 或留空
4. 点击 **保存并部署**。
5. **约 30 秒后部署完成**，Cloudflare 会免费提供一个 `*.pages.dev` 域名。
   * 项目内的 `functions/api/fund.js` 会被 Cloudflare 自动识别为无服务器反代路由 `/api/fund`，免费彻底消除任何跨域阻碍！
   * 项目内自带的 `_headers` 文件会自动为 HTML 与 Service Worker 配置 `no-cache` 规则，确保后续代码更新秒级生效。

---

### 方案 B：部署在 Vercel (1分钟搞定)

1. 将本项目代码推送到 GitHub 仓库。
2. 登录 [Vercel 官网](https://vercel.com/)，点击 **Add New...** -> **Project**。
3. 导入你的 GitHub 仓库，全部保持默认设置，点击 **Deploy**。
4. 部署完成后即可获得免费的 `*.vercel.app` 访问链接。
   * 项目内已自带 `vercel.json` 和 `api/fund.js`，Vercel 会自动启用 Serverless 代理。

---

### 方案 C：本地离线直接使用

你也可以直接双击打开 `index.html` 即可使用，数据自动缓存在你的本地浏览器中。
