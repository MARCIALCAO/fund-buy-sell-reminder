# 基金金字塔/倒金字塔买卖策略助手 (Pyramid Fund Master)

一款专为中国公募基金投资者打造的**策略记账与智能买卖点提示 Web 应用 (PWA)**。采用现代极简磨砂玻璃 (Glassmorphism) 与渐进模糊设计，电脑端与手机端全屏自适应，提供精准的阶梯买卖决策辅助。

---

## 🌟 核心功能特色

1. **实时抓取最新盘中估值与历史净值**
   * 直连天天基金/东方财富官方最新批量估值 API，自动解析盘中实时估值、涨跌幅及更新时间。
   * 支持多级降级：优先浏览器直连（已支持跨域通配），配备云端反代及公共代理池兜底。

2. **金字塔加仓与倒金字塔减仓策略模型**
   * **金字塔加仓（越跌越买）**：默认每跌 5%，提示买入总计划预算的 10%、20%、30%、40%。
   * **倒金字塔减仓（越涨越卖）**：默认每涨 5%，提示卖出持有仓位的 10%、20%、30%、40%。
   * **灵活锚点选择**：默认以「初始建仓成本价」为基准线，并支持自由切换为「持仓加权均价」或「最新交易价」。
   * **实时阶梯指示器**：横向刻度直观展现当前净值处于哪一档位区间、距离下一档还需涨跌多少 %、下一买卖点建议投入金额/赎回份额。

3. **交易日 14:00 定时抓取与多通道预警**
   * **交易日准时提醒**：周一至周五每个交易日的 14:00（场外基金申赎决策黄金期）自动执行单次估值快照。
   * **三重触发提醒**：一旦估值触及买卖点，立即触发「顶部视觉告警横幅 + Web Audio 原生清脆和弦提示音 + 浏览器原生 Notification 弹窗」。
   * **一键复制指令**：可一键复制买卖建议文本，方便粘贴到支付宝、天天基金或微信中执行操作。

4. **持仓统计与手动记账同步**
   * 自动统计总持仓市值、总投入成本、累计总盈亏与今日预估盈亏。
   * 支持快速记录加仓申购与减仓赎回，自动重新加权计算持仓份额与持仓均价。

5. **纯本地私密存储与 JSON 备份**
   * 所有持仓与交易流水均安全存储在浏览器的 LocalStorage 中，不经第三方服务器。
   * 提供一键「JSON 导出备份」与「JSON 导入恢复」，换手机或清缓存无后顾之忧。

6. **移动端深度适配与 iOS PWA**
   * 视口锁定与 `touch-action: manipulation`，彻底禁用双击缩放误触。
   * 完整支持 iOS Safari「添加到主屏幕」，全屏沉浸运行，媲美原生 App。

## 🚀 免费部署方案 (推荐：Cloudflare Pages / Vercel)

本项目无需购买云服务器或数据库，可 100% 永久免费部署至全球主流托管平台。

### 方案 A：部署在 Cloudflare Pages (推荐，全球极速且自带反代)

1. 将本项目代码推送到你个人的 GitHub 仓库中（例如 `fund-pyramid-master`）。
2. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，在左侧导航栏点击 **Workers 和 Pages** -> **创建应用程序** -> 选择 **Pages** -> **连接到 Git**。
3. 选择你刚刚推送的代码仓库：
   * **框架预设 (Framework preset)**：选择 `None` (纯静态)
   * **构建命令 (Build command)**：留空
   * **构建输出目录 (Build output directory)**：填入根目录 `.` 或留空
4. 点击 **保存并部署**。
5. **约 30 秒后部署完成**，Cloudflare 会免费提供一个 `*.pages.dev` 域名。
   * 项目内的 `functions/api/fund.js` 会被 Cloudflare 自动识别为无服务器反代路由 `/api/fund`，免费彻底消除任何跨域阻碍！

---

### 方案 B：部署在 Vercel (1分钟搞定)

1. 将本项目代码推送到 GitHub 仓库。
2. 登录 [Vercel 官网](https://vercel.com/)，点击 **Add New...** -> **Project**。
3. 导入你的 GitHub 仓库，全部保持默认设置，点击 **Deploy**。
4. 部署完成后即可获得免费的 `*.vercel.app` 访问链接。
   * 项目内已自带 `vercel.json` 和 `api/fund.js`，Vercel 会自动启用 Serverless 代理。

---

### 方案 C：本地离线直接使用

你也可以在电脑上直接双击打开 `index.html` 即可使用，数据自动缓存在你的本地浏览器中。

## 📱 iOS 端添加到主屏幕指南 (PWA 模式)

1. 在 iPhone 的 **Safari 浏览器** 中打开你的部署链接（或 Vercel/Cloudflare Pages 网址）。
2. 点击 Safari 底部中央的 **“分享”** 按钮（向上箭头的方形图标）。
3. 向上滑动菜单，找到并点击 **“添加到主屏幕” (Add to Home Screen)**。
4. 确认应用名称为 **“基金金字塔”**，点击右上角 **“添加”**。
5. 回到 iPhone 桌面，即可看到独立的应用图标，点击即可全屏打开使用，无浏览器地址栏，支持系统通知提示！
